Resumen 1: Fundamentos de HTML, Texto, Enlaces e Imágenes

Páginas 1 a 10

1. Estructura básica de HTML

HTML utiliza etiquetas de apertura y cierre para organizar el contenido de una página web. El documento se divide en HEAD, donde se encuentra información como el título, y BODY, donde aparece el contenido visible. Actualmente se recomienda declarar el tipo de documento con DOCTYPE y utilizar HTML5.

2. Formato y diseño del texto

Los párrafos se crean con P y los encabezados van desde H1 hasta H6. La etiqueta BR permite saltos de línea y HR crea una separación horizontal. B destaca texto en negrita e I en cursiva. También existen elementos para citas, texto preformateado, superíndices y subíndices.

3. Listas

UL crea listas con viñetas, OL crea listas numeradas y LI representa cada elemento. DL permite crear listas de definiciones mediante DT para el término y DD para su descripción. Las listas pueden contener otras listas. Los comentarios HTML se escriben entre <!-- y -->.

4. Caracteres especiales

Las entidades HTML permiten mostrar caracteres especiales. Algunos ejemplos son &lt; para el símbolo menor que, &gt; para el mayor que, &amp; para el signo & y &quot; para las comillas. La codificación UTF-8 permite representar correctamente letras acentuadas y la ñ.

5. Enlaces hipertextuales

La etiqueta A permite crear enlaces mediante HREF. Los enlaces pueden dirigir a otras páginas, sitios externos, secciones de la misma página o direcciones de correo electrónico mediante mailto:. Las rutas relativas permiten acceder a archivos y carpetas del mismo sitio web.

6. Imágenes

La etiqueta IMG incorpora imágenes mediante SRC. El atributo ALT proporciona una descripción alternativa. WIDTH y HEIGHT permiten indicar sus dimensiones. Una imagen también puede colocarse dentro de un enlace para que el usuario pueda hacer clic sobre ella.

Resumen 2: Alineación Avanzada, Tablas y Formularios

Páginas 11 a 20

1. Alineación y tamaño de imágenes

Las imágenes pueden colocarse junto al texto o dentro de diferentes secciones de una página. En HTML tradicional se utilizaba ALIGN para controlar su alineación. WIDTH y HEIGHT permiten especificar el ancho y el alto en píxeles. Las miniaturas son imágenes pequeñas que pueden enlazar a una versión de mayor tamaño.

2. Fondos, colores y fuentes

Los colores de una página pueden expresarse mediante códigos hexadecimales, por ejemplo #FF0000 para rojo. HTML antiguo utilizaba BGCOLOR para el fondo y FONT COLOR para el texto. También se podían emplear imágenes como fondo. Actualmente, CSS es la forma recomendada para configurar colores, fuentes y estilos.

3. Tablas

TABLE define una tabla, TR crea filas, TD crea celdas y TH representa encabezados. CAPTION agrega un título. COLSPAN permite extender una celda por varias columnas, mientras que ROWSPAN permite extenderla por varias filas. CELLSPACING y CELLPADDING eran atributos tradicionales para controlar los espacios entre celdas y su contenido.

4. Formularios

Los formularios recopilan información del usuario. FORM agrupa los campos y puede incluir INPUT, TEXTAREA, SELECT y OPTION. Para procesar los datos de forma real, normalmente se utiliza un servidor o un servicio preparado para recibirlos. Un formulario HTML por sí solo no almacena automáticamente la información ni la envía al correo.

5. Elementos interactivos

INPUT TYPE="TEXT" permite escribir texto y TYPE="PASSWORD" oculta los caracteres introducidos. TEXTAREA permite escribir mensajes largos. SELECT y OPTION crean menús desplegables. CHECKBOX permite seleccionar varias opciones, RADIO permite elegir entre opciones de un grupo y los botones SUBMIT y RESET sirven para enviar o restablecer los campos del formulario.

Resumen 3: Mapas Interactivos, Marcos y Multimedia

Páginas 21 a 31

1. Mapas de imagen interactivos

Los mapas de imagen permiten que diferentes zonas de una imagen dirijan a distintos enlaces. MAP define el mapa, AREA establece las regiones activas y USEMAP relaciona el mapa con la imagen. Las áreas pueden ser rectangulares, circulares o poligonales. Es recomendable incluir enlaces alternativos para facilitar el acceso al contenido.

2. Estructura de marcos (Frames)

Los marcos se utilizaban para dividir el navegador en diferentes paneles que podían mostrar páginas distintas. FRAMESET organizaba los paneles mediante COLS o ROWS, mientras que FRAME indicaba el contenido de cada uno. NAME identificaba un marco y TARGET permitía abrir un enlace en el panel deseado.

3. Atributos avanzados de marcos

Los marcos tradicionales permitían configurar los márgenes, las barras de desplazamiento, los bordes y la posibilidad de cambiar el tamaño de los paneles. Entre sus atributos estaban MARGINWIDTH, MARGINHEIGHT, SCROLLING y NORESIZE. Los valores _blank, _self y _top controlaban dónde se abrían los enlaces. FRAMESET y FRAME ya no forman parte del HTML moderno; actualmente se prefieren CSS y diseños adaptables.

4. Integración y reproducción de sonido

Las páginas web pueden incorporar audio para que el usuario escuche música, efectos o grabaciones. En documentos antiguos se utilizaban BGSOUND y EMBED, pero no son opciones recomendadas para páginas actuales. HTML5 incorpora AUDIO, que permite añadir controles para reproducir, pausar y ajustar el sonido. Es recomendable que el usuario controle la reproducción y que el audio no comience inesperadamente.

5. Ejemplo de aplicación

Los temas estudiados permiten construir páginas web con texto, imágenes, enlaces, tablas, formularios, mapas interactivos y multimedia. Para desarrollar un sitio moderno se recomienda utilizar HTML5 para estructurar el contenido, CSS para el diseño y JavaScript para agregar funciones interactivas.
